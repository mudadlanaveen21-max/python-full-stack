types of searching:
1 -> linear search --> searching am element one by one, arr=[5,7,11,25,64]

2 --> binary search --> taking mid element as target element --> divide and conquer
			mid == target
			target < mid
			target > mid
	--> search key we have found--> search key is nothing but mid value after element is 
            the search element
eg: Start with a sorted array.  
Example: [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]

Find the middle element.

If mid == target, return index.

If target < mid, search left half.

If target > mid, search right half.

Repeat until found or search space is empty.

👉 Example: Searching for 23

Middle of array = 16 → 23 > 16 → search right half.

New middle = 38 → 23 < 38 → search left half.

New middle = 23 → found at index 5.
